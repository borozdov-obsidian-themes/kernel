# Borozdov Kernel

A theme from the Borozdov collection. Two faces — light **Drafting**, an engineering
notebook on cream paper, and dark **Runtime**, the same notebook in a dark section. Dark
code panes with bright syntax, lilac panels, compact type and one plum for what you act on.

![Borozdov Kernel in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/kernel/main/screenshots/light.png)

![Borozdov Kernel in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/kernel/main/screenshots/dark.png)

## Principles

- **Code lives on a dark pane.** Code blocks and inline code alike sit on near-black with
  bright syntax colours, on both faces.
- **Compact engineering type.** The platform's sans with headlines tracked in hard as they
  grow; callout titles and table headers are small tracked capitals.
- **One plum.** Plum is the main button, links, a checked task and the open file; lilac is
  its soft panel for the plain note and tags; an ember wash is the highlighter.
- **Squared and flat.** 8px buttons, 12px cards, 4px tags and fields; no shadows, separation
  comes from colour and 1px lines.

## Features

- Light and dark modes, following Settings → Appearance → Base color scheme
- Code blocks and inline code on a dark pane with bright syntax colours
- Callouts as white cards with an eyebrow title in the type's colour; the plain note on
  lilac
- Tags as small lilac chips in plum
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Kernel**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the [latest
release](https://github.com/borozdov-obsidian-themes/kernel/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Kernel/`, then choose Borozdov Kernel under Settings →
Appearance → Themes.
